BTW — Side Thread
Also available from the wand menu, or with /btw <question>.

Connection

The side thread can use its own backend so a cheap model answers questions while your roleplay model keeps writing. "Main API" reuses whatever SillyTavern is connected to.
Requests go straight from the browser, so the server must allow this origin (OLLAMA_ORIGINS).
The key is stored in your SillyTavern settings, not in the secrets store.
Applied to connection-profile requests only.
